# 知识擂台题库

六年级《过程与控制》配套题库浏览页。单文件 HTML，零依赖，双击即可打开。

## 内容

- 15 课 / 240 题
- 选择题 120 道 + 判断题 120 道
- 每题含题干、选项、答案与解析

## 功能

- 左侧按课次浏览
- 关键词搜索题干
- 选择题 / 判断题筛选
- 一键显示或隐藏答案

## 使用

直接双击 `index.html`，或访问部署后的在线链接。

> 页面**默认显示答案**。若作为学生练习题使用，请先点顶部「显示答案」按钮关闭答案，否则失去练习意义。
